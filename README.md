# 🐉 挂机传奇 Farm 效率计算器

基于 [guagame.com](http://guagame.com/)（GeeM2 1.76 服务端）的挂机传奇游戏源码数据，提供 **Farm 效率计算** 和 **游戏数据库查询** 两大功能。

## 🚀 使用

直接打开 `farm-calculator.html`（单文件自包含，双击即可），无需服务器。

顶部两个 Tab 切换功能：
- **⚡ Farm 计算器** — 粘贴角色 JSON，计算每张地图的 farm 效率
- **📖 游戏数据库** — 查询装备/怪物/技能/掉落

---

## ⚡ Farm 计算器

粘贴角色 JSON（或点「加载示例」），自动计算每张地图的：

| 指标 | 说明 |
|------|------|
| **每分钟经验** | 逐怪扣防后按官方公式算击杀速度 |
| **每分钟金币** | 含专属掉落 + 通用掉落表 |
| **净金币/分** | 扣除红药 + 蓝药成本（按 autoHeal 真实选药逻辑） |
| **安全度** | 按怪物实际伤害判断能否扛住 |
| **掉落明细** | 装备/技能书/特殊物品，带概率和来源怪物 |

特性：
- **每波怪物可选**（1/3/5/10 只，与游戏内设置一致），影响 AOE/召唤/毒与承伤
- 表格可排序（点击表头），默认经验降序
- 「打不动」的图自动标注 ⚠️ 并沉底（经验/金币标 * 表示实际拿不到）
- 「等级不足」的图置灰 🔒
- 行可展开看详细掉落、蓝耗、承伤、危险怪物

## 📖 游戏数据库

左侧四个子分类：

### ⚔️ 装备物品库（348 件）
- **筛选**：职业 / 类型 / 等级范围 / 特效 / 关键词搜索
- **表格**：物品名、类型、职业、等级、攻/魔/道/防/魔防、特效
- **点击展开**：完整属性 + **掉落来源**（反向索引）
  - 列出所有掉落该物品的怪物，含概率(1/N)、怪物类型/等级、所在地图
  - 通用掉落（GENERIC_DROPS）单独标注档位（Lvl≤20 / 21-40 / >40）

### 👹 怪物图鉴（281 只）
- **筛选**：类型(普通/精英/Boss) / 大陆 / 等级范围 / 关键词
- **展开**：怪物技能、掉落物品、所在地图

### ✨ 技能库（60 个）
- **筛选**：职业 / 类型(攻击/被动/增益/召唤/辅助/治疗) / 关键词
- **展开**：威力、加成、冷却、AOE、描述

### 🗼 通天塔（30 层）
- **筛选**：层数范围 / 类型(含Boss/含精英) / 关键词搜索怪物名
- **表格**：层、门票、怪物构成、总HP、最高等级、类型、掉落预览
- **点击展开**：逐怪完整属性 + 技能 + 掉落表
  - `ref` 怪物引用怪物图鉴；自定义怪（深渊/邀月/祭血心魔等）标注「通天塔专属」
  - 注明门票金币、每天每层限1次、不能越层、塔内爆率×2、通关30层+1000万解锁二大陆

## 📐 算法说明

### Farm 计算器（波次模型）

严格复刻 game.js 的「波次 N 只同场」战斗：玩家有 1 个主目标，**单点技能只打主目标，AOE/召唤/毒打全场**。

**伤害分两路**：
- **单点流 DS**（扣该怪防，仅主目标）：物理段 + 魔法段 + 施毒术 DOT + 特殊（火焰/连击戒）
- **AOE流 DA**（每只怪都吃，不扣防）：AOE溅射 + 召唤群攻 + 瘟疫/毒云 DOT

**清波公式**：

```
清波回合 T = N×H / (DS + N×DA)
每分钟击杀 = 60 × (DS + N×DA) / H × 0.95损耗
```

（N=波次大小，H=加权HP；纯单点退化为 60×DS/H，纯 AOE 退化为 60×N×DA/H）

**承伤**：每回合 = 平均存活(N/2) × 单怪伤害 × (1−减伤) × 分摊率
- 减伤 = Σ buff 技能加成（魔法盾0.3 / 分身0.4 / 阴阳盾0.45…，上限0.85）
- 分摊率：有召唤宝宝时怪物 40% 打宝宝（玩家承伤×0.6）；道士隐身术+宝宝时怪物 100% 打宝宝（玩家承伤≈0）

**其他**：
- 逐怪扣防：单点流对每只怪单独扣其物防/魔防
- 蓝药：每个无冷却单体攻击技能耗 2MP/回合，地图掉落药水按各自档位折算抵扣
- 红药：承伤 × 回合数，减白嫖回血

### 蒙特卡洛模拟（死亡/时 🎲）

解析式模型用**均值**算承伤，看不到方差——而真实战斗里伤害是攻/防**双重随机 roll**（`atk - def×0.6`，各自独立均匀分布），波次首回合 N 只怪齐射的 burst 可能接近满血，且原版**一回合一共只喝一瓶红药**（回合末结算，怪物先打完）。均值模型会严重低估死亡风险。

为此新增 `simulateMap()`：逐回合复刻原版战斗循环（参考 `docs/reference/origin-game.js`，抓取自 guagame.com），跑 3000 回合蒙特卡洛，输出真实的**死亡/时**与受死亡拖累后的实际收益：

- 伤害逐次 roll（普攻 roll + 魔法段 ±10% roll，攻/防独立随机，防御 ×0.6 系数）
- 波次首回合 N 只全在场齐射，随击杀递减（不是解析式的 N/2 平均）
- 怪物技能全结算：魔法（扣魔御）、毒（3回合DOT，不吃减伤）、麻痹/冰冻（下回合全怪围殴）、召唤（最多2只援军每回合输出）、吸血
- 喝药：回合末，HP<阈值喝一瓶（AI 按缺口选药、金币不足降级），**一回合一瓶**
- 死亡：损失 1% 金币、满血复活、**当前波清零重刷**（打了一半的怪作废，拖累实际收益）

⚠️ **HP 喝药阈值必须与游戏内「自动喝药」设置一致**（页面右上角下拉，原版默认 70%）。阈值对死亡率影响极大：39级法师在石墓阵七层，70% 阈值几乎不死，30% 阈值约 150 死/时。

### 校准说明

理论模型，沿用 0.95 损耗系数（波次切换/save 开销）。早期「法师 Lv18 尸王殿 0% 误差」是低 AOE 场景的巧合；新模型在多怪/AOE/道士场景更准（道士靠召唤+毒打全场，清场效率随波次放大）。如需精校，可用实测数据微调 0.95 系数。

## 🔧 构建

`farm-calculator.html` 由构建脚本生成：

```bash
node build.js
```

源码文件：
| 文件 | 说明 |
|------|------|
| `app.js` | 核心算法 + 数据库逻辑（getStats / getDPS / calcMap / buildReverseIndex / 渲染） |
| `style.css` | 样式 |
| `ui.html` | 页面结构（Tab 栏 + 计算器视图 + 数据库视图） |
| `build.js` | 组装脚本（数据文件 + 源码 → 单 HTML） |

游戏数据（来自 guagame.com 源码）：
| 文件 | 内容 | 数据量 |
|------|------|--------|
| `expTable.js` | 经验表 | 100 级 + |
| `jobStats.js` | 职业成长（战/法/道，260 级） | 3 职业 |
| `monsters.js` | 怪物（HP/攻防/经验/技能） | 281 只 |
| `maps.js` | 地图（怪物投放/等级要求） | 122 张 |
| `items.js` | 装备物品（12 类） | 348 件 |
| `skills.js` | 技能（6 类） | 60 个 |
| `drops.js` | 掉落表（专属 DROPS + 通用 GENERIC_DROPS） | 96 怪专属 + 3 档通用 |
| `tower.js` | 通天塔副本（30 层怪物/门票） | 30 层 |
